# Module 1: App Shell + Observability

## Context

This is the first module of the RAG masterclass. We're building the foundational app shell that all subsequent modules build upon: authentication, chat UI with streaming, OpenAI Responses API integration (managed RAG), and LangSmith observability.

**Complexity: ⚠️ Medium** - Multiple interconnected components (auth, chat, OpenAI, observability) but each is straightforward individually.

## Key Technical Notes

**OpenAI Responses API:**
- Simpler than old Assistants API (deprecated Aug 2026)
- Stateless by default - send conversation history each request
- Built-in `file_search` tool for managed RAG
- Stream with `stream=True`

**Why store in Supabase if OpenAI manages threads?**
- UI needs thread list display
- RLS for user data isolation
- Persistence beyond OpenAI retention limits
- Schema ready for Module 2 transition

**SSE over WebSockets:**
- Simpler (HTTP-based)
- One-way streaming sufficient for chat
- Better proxy/CDN compatibility
- FastAPI built-in support
